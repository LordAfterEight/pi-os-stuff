# What is this?
This is some aarch64 OS experimentation intended to be run on my Raspberry Pi 4 SBC.
The main reason I'm doing this is because I don't want it collecting dust and I want
something to do while reading my copies of **Modern Operating Systems** and
**Operating Systems in Three Easy Pieces**, to kind of follow along and implement
stuff from these books.

## LLM-Generated Code
You *will* find LLM-generated code in this repository. However, it will always
be marked as such using comments, including the model used, when it was generated,
and maybe some additional notes on why and how.
Assume all other code to be human-written, by me. **:3**
